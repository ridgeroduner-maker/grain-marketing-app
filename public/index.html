    How alerts work (and their limits)

    Alerts are stored only in this browser (localStorage / IndexedDB). They are checked every time you open the app and about every 15 minutes while it is open. Data is end-of-day, so a given alert can only fire once per day's report.

    No server = no true push. Web Push needs a push service plus a server that sends messages, so a closed app cannot be woken on a schedule by this version. On Chrome/Edge (Android & desktop) an installed app may also get Periodic Background Sync checks (experimental, browser-throttled, not guaranteed). iOS needs the app added to the Home Screen (iOS 16.4+) and only supports notifications while using a push server.
